\section{AutoResearch Evidence-Discovery Workflows}
\label{appendix:autoresearch}

This appendix gives the complete account of the two AutoResearch evidence-discovery workflows
summarised in the main text: \emph{Citation Set Completion} (CSC) and \emph{Literature Set
Expansion} (LSE). The main-text tables report only the causal contrast (correct minus rewired
connectivity); here we report absolute performance for every condition, the construction funnels,
the diagnostics that localise where the graph helps, and the frozen artifacts needed to reproduce
each number.

\subsection{Instance Construction}
\label{appendix:ar-construction}

CSC instances are built from real paragraphs containing $2$--$5$ resolved citations. One citation
is revealed as an \emph{anchor}; the remaining citations form the target set the system must
recover. LSE instances take a source paper's title and abstract only, with citation markers
scrubbed, and ask for a ranked set of earlier relevant papers; the source's own resolved earlier
references serve as weak supervision.

Table~\ref{tab:ar-funnel} separates the large construction pool from the small frozen evaluation
samples. Note the asymmetry: CSC filters a $1.2$M-edge pool down to $57{,}947$ instances and then
freezes $5{,}000$ for fixed retrieval, whereas LSE screens source papers directly.

CSC is split by source paper ($70/15/15$) so no source appears in more than one split; target-set
sizes in the frozen slice are $1/2/3/4$ remaining targets for $2695/1252/680/373$ instances.
LSE is split by $(\text{year}, \text{primary category})$ cluster, with whole clusters assigned to
dev or screen ($116$ clusters, $13$ held out). LSE gold sets have mean $16.6$ and median $14$
references (range $5$--$88$).

\paragraph{The LSE $1200 \rightarrow 909$ step is a split, not an exclusion.}
All $1{,}200$ frozen LSE sources are retained; none is discarded after freezing. The frozen set is
partitioned by a \emph{predeclared} grouped development/screening split on
$(\text{year}, \text{primary arXiv category})$ clusters: $13$ of $116$ clusters
($291$ sources) form the development split and the remaining $103$ clusters ($909$ sources) form
the screening split, with $291 + 909 = 1200$ exactly. Whole clusters are assigned to one side, so
the realised proportion ($24.3\%$ development) does not land exactly on the nominal $20\%$. The
\texttt{split} label is stored per record inside \texttt{frozen\_ids.jsonl} itself.

The split rule is recorded in \texttt{construction\_manifest.json} under
\texttt{predeclared\_rules.splits}, and the ordering is verifiable from file timestamps: the frozen
identifiers and their split labels were written at 04:45, whereas the first retrieval numbers
(\texttt{retrieval\_results.csv}) appeared at 05:27 and the gate decision at 05:33 --- roughly $40$
minutes later. No split assignment could have been informed by an observed arm score.

\textbf{The screening split ($n{=}909$) is the single canonical evaluation set for LSE fixed
retrieval}, and it is the set the main text reports. Metrics were also computed over all $1{,}200$
frozen sources and are retained in the artifacts for completeness; that superset passes the launch
gate as well ($+0.2384$ versus BM25, $+0.1790$ versus rewired hybrid on R@50), so reporting the
screening split is not a choice among a passing and a failing variant. The two must not be mixed in
a single table. The $150$ LSE agent instances are drawn entirely from the screening split, giving a
strict nesting $1200 \supset 909 \supset 150$, and the development split was used only for
interface debugging and the agent smoke test.

\paragraph{Weak supervision.} An author's bibliography is incomplete and selective. On the frozen
LSE set the mean unresolved-reference rate is $0.68$, so roughly two-thirds of bibliography entries
never resolve to an in-corpus paper. Absolute LSE recall is therefore a \emph{floor}, not a
measurement of topical recall, and only paired between-condition differences are interpretable.

\subsection{Temporal Validity and Leakage Prevention}
\label{appendix:ar-leakage}

For a source paper $s$ with cutoff $t_s$: anchors and targets must be available strictly by $t_s$;
$s$ is excluded from all candidate pools; every citation and paragraph edge emitted by $s$ is
removed; traversal evidence is built only from papers available before $t_s$; and the evaluation
paragraph itself may not create the anchor--target relation.

\paragraph{An identity defect that defeated masking.} The citation graph mixes arXiv identifier
spellings: \texttt{cites} edges are version-stripped, but $73{,}178$ of $165{,}555$
\texttt{has\_paragraph} edges carry an explicit version (e.g.\ \texttt{paper:2002.08165v2}).
$6{,}198$ base identifiers therefore existed as two unconnected nodes. Masking on the literal
source identifier left the source reachable through its versioned twin, which is exactly the
forbidden source-derived channel. Exposure was $45.4\%$ of CSC instances and $223/1200$ ($18.6\%$)
of LSE sources, leaving $3{,}070$ source-owned paragraph nodes unmasked. All paper identity is now
resolved on the version-stripped base identifier in every graph variant, and degree preservation was
re-verified after the merge. Both workflows were rebuilt and re-audited; superseded artifacts are
preserved under \texttt{superseded\_v1/} and were not used for any reported number.

After the fix, the CSC audit checked $2{,}204{,}525$ candidates across all arms and found $0$
violations; LSE found $0$ future-dated candidates, $0$ source-in-results, and $44{,}346$ blocked
source-edge traversal attempts, with an independent re-audit of $15{,}000$ returned identifiers
against a freshly queried date table.

\subsection{Retrieval and Graph Conditions}
\label{appendix:ar-conditions}

Correct and rewired conditions differ \emph{only} in the backing adjacency: node identities, text,
metadata, degrees, prompts, tool schemas and budgets are identical, which is asserted at run time
by comparing a prompt/schema hash. The rewired graph is the degree-preserving variant
($989{,}123$ edges in both; per-relation in- and out-degree sequences element-wise identical). We
use untyped connectivity throughout.

Graph expansion scores candidates by Adamic--Adar proximity from the revealed anchor over at most
two hops with a fixed one-hop bonus, label-free and identical across variants. Hybrid conditions
fuse BM25 and graph rankings by reciprocal rank fusion ($k{=}60$). CSC uses $K{=}50$ retrieved
candidates; LSE uses $K{=}50$ with $10$ BM25 seeds, at most three hops, and a per-node cap of $25$.

\subsection{Interactive Agent Protocol}
\label{appendix:ar-protocol}

Agents run a stateful multi-turn loop. Intermediate actions and final answers use \emph{separate}
parsers, so an unrecognised object is malformed rather than silently accepted as an answer. Agents
receive no prepopulated candidate list.

\paragraph{Disclosed intervention.} Each condition enforces a \emph{mandatory minimum research
phase} before an answer is accepted (flat: at least one \texttt{search}; graph conditions: at least
one \texttt{search} and one \texttt{traverse}; compact hybrid: at least one \texttt{hybrid\_search}).
A premature finalisation is refused with a deterministic message and costs no tool call. This is
part of the protocol, not an observed model behaviour, and is required because under a natural
action interface neither model invoked any tool at all (Appendix~\ref{appendix:ar-diagnostics}).

Budgets, identical in every condition: at most $8$ tool calls, $6{,}000$ observation tokens,
$10$ candidates per call, one deterministic format-repair turn, and one forced-answer turn if the
tool budget is exhausted without a voluntary answer. Checkpoints are Qwen2.5-7B-Instruct,
Qwen3-8B, and Qwen2.5-32B-Instruct (GPTQ Int4, the only quantised model); decoding is greedy with
a transcript-keyed response cache so identical transcripts yield identical responses across
conditions.

\subsection{Evaluation Metrics and Statistical Testing}
\label{appendix:ar-stats}

CSC reports macro target recall at $5$ and $10$, set $F_1$, set recall and R-precision; LSE reports
recall and nDCG at $10$, $20$ and $50$ plus MAP@$50$. Invalid or missing answers score zero on every
effectiveness metric and are counted separately as an unanswered rate.

All tests are paired over instances: bootstrap confidence intervals with $10{,}000$ resamples and
paired sign-flip permutation tests with $10{,}000$ permutations, seed $20260925$, resampling unit =
instance. Holm correction is applied only within an explicitly declared confirmatory family, per
model, never pooled across models. The declared primary comparisons, fixed in code before any
inference, are \texttt{correct} versus \texttt{rewired} traversal on CSC recall@$10$ and on LSE
recall@$50$.

Three findings, stated at the strength the data supports.

\textbf{Correct connectivity helps, and replicates.} The correct-minus-rewired contrast is positive
and Holm-significant on all three models for CSC and both models for LSE, at $94$--$98\%$ traversal
uptake, so it is an effect of topology rather than a failed-uptake artifact. Effect sizes are stable
across a $4.5{\times}$ parameter range.

\textbf{Sequential interaction adds nothing detectable.} No agent beats its own matched-pool replay
after correction; several point estimates are slightly negative. Whatever the agent gains comes from
the candidate pool its tools assemble, not from planning across turns. We therefore do \emph{not}
claim that agents outperform matched replays.

\textbf{A compiled retrieval interface beats agentic traversal.} On LSE the fixed correct-hybrid
list reaches R@50 $=0.423$ while the best agent reaches $0.281$; the compact-hybrid agent is
$0.142$ \emph{below} the fixed list it was effectively given ($p_{\text{Holm}}=0.0006$). On CSC the
fixed correct-hybrid list ($0.427$) matches the best agent ($0.426$).
